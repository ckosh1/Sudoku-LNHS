Sudoku:
A graphical Sudoku game built with Python and Pygame.

About:
My group created this project for a dual enrollment course to build a playable Sudoku game while practicing Python, object-oriented programming, algorithms, and graphical user interfaces.

The game generates randomized Sudoku puzzles with Easy, Medium, and Hard difficulty levels. Players can enter numbers using the keyboard, navigate the board with the mouse or arrow keys, reset puzzles, and receive a win or game-over screen.

Features
- Randomly generated Sudoku puzzles
- Easy, Medium, and Hard difficulty levels
- Graphical interface using Pygame
- Mouse-based cell selection
- Keyboard number input
- Arrow-key navigation
- Number sketching
- Puzzle reset functionality
- Win and game-over screens
- Automatic solution checking
- Object-oriented board and cell classes
- Recursive backtracking for generating valid Sudoku boards


Technologies
- Python
- Pygame

  
Project Structure
- main.py — Runs the game, handles user input, manages game states, and displays the graphical interface.
- sudoku_generator.py — Generates Sudoku boards, contains the SudokuGenerator, Board, and Cell classes, and handles board validation and solution checking.

Acknowledgments:
